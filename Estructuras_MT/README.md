## Cómo cargar la base de datos

### SQLite (recomendado, 1 comando)
```bash
sqlite3 proyecto_electrico.db < schema.sql
```

### PostgreSQL
Cambia `GENERATED ALWAYS AS (...) VIRTUAL` por `GENERATED ALWAYS AS (...) STORED` y quita `AUTOINCREMENT` (usa `SERIAL` o `GENERATED BY DEFAULT AS IDENTITY`).

### Python (pandas)
```python
import pandas as pd
materiales = pd.read_csv("data/materiales.csv")
uucc       = pd.read_csv("data/uucc_material_estructura.csv")
# join por codigo_material = codigo
df = uucc.merge(materiales, left_on="codigo_material", right_on="codigo")
```

## Query de ejemplo

```sql
-- ¿Cuánto cuesta en materiales la estructura MTA-302 (2/0-4/0) (55-5)?
SELECT
    u.descripcion,
    u.cantidad,
    m.precio_igmelec AS precio_unit,
    ROUND(u.cantidad * m.precio_igmelec, 2) AS subtotal
FROM uucc_material_estructura u
LEFT JOIN materiales m ON u.codigo_material = m.codigo
WHERE u.estructura = 'MTA-302 (2/0-4/0) (55-5)'
ORDER BY subtotal DESC;
```
